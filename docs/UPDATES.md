# Обновление материалов курса

Источник: [kryovox/java-oracle-start-template](https://github.com/kryovox/java-oracle-start-template).
Workflow запускается ежедневно в 06:00 по Москве (03:00 UTC) и вручную.
Фактическое время зависит от очереди GitHub. Шаблон должен быть публично доступен для чтения.

## Что переносится

- `docs/`, `lectures/`, `materials/`, `assets/`, общие настройки Git и редактора — версия преподавателя.
- Общие README разделов practice, homework, exams и README.md / tasks.md в папках работ первого уровня — инструкции преподавателя.
- Новые заготовки в папках работ — добавляются только при отсутствии файла.
- Существующие решения Java, SQL, проекты и отчёты — сохраняются.
- Корневой README, .universal-trainer.json, .github и папки practice/trainer, homework/trainer, exams/trainer — исключены из переноса.
- Удаления файлов нет; удалённая заготовка может появиться снова, если она осталась в шаблоне.

## Как получить материалы

1. В личном репозитории откройте Actions, при необходимости включите workflows.
2. Выберите «Обновление материалов курса» → Run workflow → main.
3. Дождитесь зелёного статуса и проверьте сводку.
4. В IntelliJ IDEA сохраните свои изменения, сделайте коммит и выполните Git → Pull (или Update Project).
5. При конфликте сохраните обе версии и обратитесь к преподавателю.

Workflow создаёт отдельный коммит от github-actions[bot]. Он использует GITHUB_TOKEN с contents: write; отдельный секрет не нужен. При запрете push или одновременной записи Universal Trainer запустите workflow повторно после завершения другой операции.

В уже созданных копиях без workflow его нужно один раз добавить вручную с разрешения владельца. Обновления самого workflow автоматически не распространяются.
