# Настройка Java

Установите IntelliJ IDEA и JDK 25 LTS. В File → Project Structure → Project выберите SDK. Для первой программы достаточно JDK 21. Из корня репозитория в терминале можно выполнить `cd practice/01-hello-java`, `javac -encoding UTF-8 Main.java`, `java Main`. Ожидаемый вывод: `Hello, Java!`. Oracle, JDBC и Spring подключаются позднее по материалам курса.
