# Java + Oracle

Учебный репозиторий по МДК.01.20 «Программирование с использованием технологии Java и СУБД Oracle».

| Поле | Значение |
|---|---|
| Студент | Имя Фамилия |
| Группа | Укажите свою группу |
| Учебный год | Укажите учебный год |
| Среда | IntelliJ IDEA, JDK 25 LTS |

## Начало работы

1. Создайте личную приватную копию через Use this template → Create a new repository. Название: `java-oracle-start`, ветка `main`.
2. Пригласите преподавателя в репозиторий, согласовав его аккаунт. Заполните карточку выше.
3. Клонируйте свою копию через IntelliJ IDEA → Get from VCS. Установите JDK 25 (для первых занятий допустим 21).
4. Откройте `practice/01-hello-java/Main.java`, установите Project SDK и запустите main. Подробности: [SETUP](docs/SETUP.md).
5. Установите [Universal Trainer App](https://github.com/apps/universal-trainer/installations/new) только в этот репозиторий. [Правила сдачи](docs/SUBMIT.md).
